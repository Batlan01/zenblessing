A gépeken egy kis PowerShell agent fut, ami lekéri a neki szóló csomagokat és telepíti őket. Két módon indul: GPO startup script (első bekötéskor / induláskor) és ütemezett feladat (rendszeres polling a későbbi változásokhoz). A bootstrap mindkettőt beállítja.

Letöltések
bootstrap.ps1 (GPO startup) agent.ps1
Az agentet nem kell kézzel szétküldeni — a bootstrap mindig a szerverről tölti a friss verziót.
GPO beállítás (egyszer)
  1. Másold a bootstrap.ps1-et egy elérhető helyre (pl. SYSVOL netlogon megosztás), vagy hagyd a szerveren.
  2. Group Policy Management → új GPO a cél OU-ra (ahova a gépek kerülnek).
  3. Computer Configuration → Policies → Windows Settings → Scripts → Startup → PowerShell Scripts fülön add hozzá a bootstrap.ps1-et.
  4. A startup script SYSTEM-ként fut (rendszergazda jog a telepítéshez megvan).
  5. A bootstrap létrehoz egy DomainDeployAgent ütemezett feladatot is (induláskor + óránként), így a későbbi új csomagok is települnek.
MSI/EXE telepítők

A saját telepítőket tedd a szerver static/installers/ mappájába; a lépésnél az identifier mezőbe a fájlnév kerül (pl. MyApp.msi), vagy közvetlen URL.

choco/winget esetén csak a csomag-ID kell (pl. googlechrome, Mozilla.Firefox).
